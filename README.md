# Airbnb pricing plan

A static page (GitHub Pages) that compares my Windsor Island house's Airbnb prices with nearby peer houses for the next 45 days, and gives a reduce / keep / increase call for each open gap in my calendar.

- `index.html` – the page (all logic runs in the browser)
- `data/` – daily price and calendar history, refreshed each day
- `thumbs/` – one photo per house

Turn on: Settings → Pages → Deploy from a branch → `main` / root.
